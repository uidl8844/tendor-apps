Tendor Large File Finder Pro

Large File Finder Pro keeps a prioritised list of the biggest files with their path and size, so you can decide what to move or remove first. At the end you export a disk-space report as text.

  • Largest files first
  • Path and size per entry
  • Mark move, archive or delete later
  • Disk-space report export
  • No cloud scanner
  • Local data file on your PC

Einmalzahlung, kein Abo. Alle Daten bleiben auf deinem PC. Windows 10/11, 64 Bit.
